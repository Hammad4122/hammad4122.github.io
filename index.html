About

I ship things people can install and run.

I'm a second-year Software Engineering student in Islamabad. Most of my work sits in one place: the gap between raw data and a decision someone has to make. Cleaning it, checking it didn't quietly break, putting it somewhere readable, and automating the whole run.

That's how PandasTrace happened. I lost rows inside a long Pandas chain and had no idea which step ate them, so I built a wrapper that logs row counts, nulls, duplicates, and memory at every step — then published it so other people wouldn't have to repeat the debugging.

Alongside Python I work in C++17 with Qt6 and SQL Server on desktop software. Different tools, same instinct: make the system tell you what it's doing.

Published package

~/pandastrace

PandasTrace

Python · pip installable · 23 passing tests

Long Pandas chains lose rows silently. PandasTrace wraps your DataFrame and records what happened at every step — rows in, rows out, nulls, duplicates, memory — then exports the whole trace to JSON or CSV so you can hand it to someone else as evidence.

$ pip install pandastrace
